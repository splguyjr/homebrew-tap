# splguyjr/homebrew-tap

개인 Homebrew tap.

```bash
brew install splguyjr/tap/anhamdie
```

설치하면 소스에서 로컬 빌드(1~2분)한 뒤 `/Applications/AnhamDie.app`에 자동 설치됩니다.
제거는 `brew uninstall anhamdie` (앱까지 함께 제거됨).

| Cask | 설명 |
|---|---|
| `anhamdie` | macOS 메뉴바 투두 앱 — 플로팅 오버레이·브리핑·Jira식 이월 ([저장소](https://github.com/splguyjr/anham-die)) |
